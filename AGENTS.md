# Project Instructions

## Goal
Build a polished online instructor website that showcases classes, teaching videos, schedule and contact information.

## Important
- Do not invent real instructor details.
- Keep placeholder content clearly replaceable.
- Prioritize mobile responsiveness.
- Keep the UI clean, trustworthy and education-focused.
- Videos should initially be embedded from YouTube/Vimeo rather than stored locally.
- Future dynamic content can use Supabase.

## Before production
- Replace all placeholder text.
- Add instructor branding.
- Add real social links.
- Connect contact form to a backend/service.
- Add SEO metadata.
- Test mobile, tablet and desktop.
