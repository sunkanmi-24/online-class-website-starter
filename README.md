# Online Class Website Starter

A modern Next.js starter for an online instructor/teacher website.

## Current goal
The owner can present what they teach, publish class information, showcase videos, show a schedule, and provide contact/join links.

Because the instructor details are not known yet, the project uses editable placeholder content.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- App Router

## Pages
- Home
- About
- Classes
- Videos
- Schedule
- Contact

## Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000
